# Castle Defender – Download

Koop-Survival in einer Blockwelt: Die Orcs haben alle Lande erobert, nur der **Kristall der Hoffnung** steht noch.
Baut tagsüber eine Burg um den Kristall und verteidigt ihn nachts – allein oder mit bis zu 4 Spielern online.

## Herunterladen

**[➜ Neueste Version herunterladen](https://github.com/CodeMonkey1990420/castle-defender-download/releases/latest)**
(unter „Assets“ die Datei `CastleDefender-…-Windows.zip` anklicken)

Nur für Windows (64 Bit).

## Starten

1. Die Zip-Datei komplett entpacken (Rechtsklick → „Alle extrahieren“).
2. `CastleDefender.exe` im entpackten Ordner starten.
3. Zeigt Windows „Der Computer wurde durch Windows geschützt“: **Weitere Informationen → Trotzdem ausführen**
   (das Spiel ist nicht signiert).
4. Fragt die Windows-Firewall: **Zugriff zulassen**.

## Zusammen online spielen

- **Host:** Hauptmenü → „Neues Spiel“ → „Koop online (Raumcode)“. Der Raumcode steht oben rechts und im Pausenmenü (Esc).
- **Mitspieler:** Hauptmenü → „Mitspielen“ → Raumcode eingeben → „Beitreten“.

Alle brauchen dieselbe Version. Mehr steht in der `LIESMICH.txt` in der Zip-Datei und im Spiel unter „So spielst du“.
